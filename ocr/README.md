# OCR 验收打分工具（#120）

本目录提供 OCR 识别结果的验收打分脚本，用于回答「识别是否准确、生僻字是否不丢不假、列是否分对了」。

> 状态：#120 验收表 9 项指标已全部实现。数据集真实覆盖、双人核定等仓外事项见 `dataset-manifest.md`「待补事项」。

## 本目录文件

- `score.py` — 打分脚本（见下方指标）
- `charset.py` — 难字 / 弃权字符集定义（与 rareCharacters.js、corpus_probe 对齐）
- `extract_text.py` — 数字原生 PDF 文本层提取工具
- `selection-notes.md` — OCR 选型建议书（非约束性）
- `dataset-manifest.md` — 验收数据集清单（语料、排版、许可状态）
- `test_score.py` — score.py 回归测试（标准库 unittest）

## 用法

```bash
python score.py --gold 标准答案.csv --test 待测结果.csv [--key 页码]
```

可选参数：

- `--key 列名`：按该列值对齐两份 CSV（如 `PDF页码`）；留空则按行顺序对齐。

## 输入约定

- 按**标准答案的字段表**打分：待测缺列时，该列按空值计错（不会从分母剔除、不会因此得满分）。
- 待测多出的列不参与打分，但会给出提示。
- 若指定 `--key`，按键值对齐；gold 有 test 无 / test 有 gold 无 的键分开计数。
- 编码：UTF-8（含 BOM 也支持）。

## 已实现指标（9 项，与 #120 验收表一一对应）

- 字级错误率 CER —— 逐字段 Levenshtein 编辑距离 ÷ 标准字符数，clamp 到 [0,1]
- 字级准确率 —— 1 - CER
- 列归属准确率 —— 单元格内容与标准答案完全一致的比例（按 gold 字段表全量比较）
- 行对齐率 —— 按键值或行序实际匹配上的行数 ÷ 标准行数（不是简单的 n_test/n_gold）
- 生僻字覆盖 ——（认对 + 合法弃权）/ 难字总数
- 静默替换率 —— 难字被换成常见字（非弃权、非难字）的次数 ÷ 难字总数
- 集外字可表示性 —— 1 − 难字被丢弃比例
- 合并未分离检出率 —— 见下方「合并与弃权指标口径」
- 弃权质量 —— 见下方「合并与弃权指标口径」

## 难字与弃权判定（关键语义）

- **难字**：罕见汉字（Ext A/B–F/G、兼容表意、兼容补充，与 `rareCharacters.js` 对齐）、IPA、带圈序号、上标调号。范围集中在 `charset.py`。
- **合法弃权**：空格、私用码位（PUA U+E000–U+F8FF）、IDS 运算符（U+2FF0–U+2FFF）。命中这些不算静默替换，而计入「生僻字覆盖」的合法弃权。
- **难字比对用 Levenshtein 回溯对齐**：插入/删除不毁掉后面难字的判定；只有「替换」位置的难字才判静默替换；删除位的难字记为「被丢弃」。

## 合并与弃权指标口径（新增两项）

**合并未分离检出率**（对应验收表「多列被并成一格的情况被标记出的召回」）：

- **合并案例**：gold 相邻两非空字段 A、B，test 中 A 列的格子去掉弃权标记字符（空格/PUA/IDS）后，恰好等于 A、B 各去掉弃权标记后的按序拼接（贪心按 A→B 对齐）。即「左格吞并右列」形态。
- **被标记（检出）**：合并格在 A 段结束、B 段开始的**边界处**存在弃权标记字符（空格或 PUA/IDS），表示引擎承认这两块内容之间有分界。右列**内部**的空格不算边界标记。
- 检出率 = 被标记的合并案例 ÷ 合并案例总数。**无合并案例时为 `None`（无数据）**——全部正确的输出不该由此指标得满分，也不该得 0 分。
- 已知口径限制：仅判「左格吞并相邻右列」的两列合并；三列及以上连续合并、或内容整体右移的错列，由「列归属准确率」计错覆盖。

**弃权质量**（对应验收表「标为低置信的格中确实需要人工的比例」，格级）：

- **低置信格**：test 单元格含至少一个 PUA（U+E000–U+F8FF）或 IDS（U+2FF0–U+2FFF）占位符。空格**不算**——正常释义文本里空格随处可见，不构成弃权声明。
- **确需人工**：该低置信格与 gold 对应格内容不完全一致。
- 弃权质量 = 确需人工 ÷ 低置信格总数。**没有弃权格时为 `None`（无数据）**。
- gold 本身含 PUA/IDS 且被精确复制时，该弃权计为「不需要人工」（wasted），鼓励引擎只在真读不出时弃权。

## 边界情况规则

- 空列：标准为空、待测为空 → 列归属正确；标准为空、待测非空 → 列归属错误。
- 同格多符号：一个单元格含多个字符时，CER 按整格编辑距离计；难字按回溯对齐逐字判。
- PUA / IDS / 空格：在难字判定中判为合法弃权（见上），计入生僻字覆盖，不计静默替换；
  但在弃权质量中只有 PUA/IDS 算格级低置信标记（空格不算）。
- **跨页条目**：一条词典条目跨页时，gold 以相同键值（`--key 页码` 允许同键多行，或同一条目
  拆成多行各带本页页码）出现多行。口径如下：
  - 同键多行按行序逐一配对、多退少补（见 `score()` 的 key 分支），不会静默丢行；
  - 待测把跨页内容并成一行 → 该键下「仅标准答案有」计数增加、行对齐率下降，
    跨页合并本身不在合并检出率口径内（它不是相邻列并格，而是行并格）；
  - 待测多出的跨页续行按「仅待测结果有」计，不被当作独立条目打分。
- 无数据保护：没有任何可比对单元格时，所有比例型指标输出 `None`，不报满分。
